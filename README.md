- 不含英语模块

## GitHub Pages 部署

将这五个文件上传至既有仓库 `desktop-tutorial` 的根目录并提交：

- `index.html`
- `app.js`
- `questions.js`
- `courses.js`
- `cases.js`

不要上传 `build.py`、`upgrade.py` 或测试脚本。等待 Pages 部署后刷新原网址；如资源被缓存可按 Ctrl+F5 强制刷新。

## 数据安全与功能范围

- 旧版学习记录：沿用 `laohou-training-final-v6` 本地存储键，升级不会主动清空；原270道题ID保持不变。
- 内容复盘：仅存当前浏览器，可通过“学习数据”导出整体JSON备份，也可导出内容复盘CSV。浏览器换设备不会自动同步。
- 公开仓库的源码里不要写入真实客户隐私、密码或API密钥；真实案例要脱敏。
- 开放题目前采用人工对照参考框架的方式；**没有AI自动批改、账号登录或云端同步**。
- 新增内容侧重实战训练，不代表官方实时平台算法或必然有效的流量方法。
